# Nexus Starship Guardians

**Nexus Starship Guardians** is the canonical product name for this project going forward.

The autonomous specialist role is **Guardian**. Use **Guardian** / **Guardians** in product-facing UI, documentation, prompts, CLI help, architecture diagrams, and future integrations.

## Naming standard

- Product: **Nexus Starship Guardians**
- Specialist: **Guardian**
- Specialist team: **Guardian Swarm**
- Short product name: **Starship Guardians**
- Short code/branch prefix: **NSG** / `nsg/`
- Python distribution: `nexus-starship-guardians`
- Preferred CLI: `nexus-guardians`

The existing GitHub repository URL still uses its original repository slug. Internal legacy data-model field names may remain where an immediate schema break would invalidate stored records or clients, but all new product-facing terminology and new APIs should use Guardian naming.
