## Why this matters

A cinematic prototype cannot be fully preserved by a screenshot alone. For each motion-heavy design, the target archival package is:

1. Figma identifiers and hierarchy
2. Full-size reference screenshots
3. Original images / SVG / video media
4. Desktop playback recording
5. Mobile playback recording where applicable
6. Motion/scene graph specification
7. Faithful web reconstruction
8. Checksums for binary assets

## Archive policy

Do not overwrite original design records. Enhanced Lucio builds should always create a new version while preserving `FIGMA_VAULT_V1.0` as the immutable source reference.
